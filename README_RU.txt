Gold & Bitcoin — версия с серверной функцией для котировок Capital.com

ВАЖНО
- Это только получение цен. Отправки торговых ордеров в коде нет.
- Графики пока демонстрационные, даже когда цифры цены уже реальные.
- Сначала рекомендуем CAPITAL_DEMO=true. Не вставляйте API-ключи в index.html и не отправляйте их в чат.

В папке проекта должны быть:
  index.html
  netlify.toml
  netlify/functions/prices.mjs

Для работы нужен деплой через Git-репозиторий (например, GitHub), связанный с Netlify. Простая загрузка одного index.html через Netlify Drop не публикует serverless-функции.

После подключения репозитория откройте Netlify → Site configuration / Environment variables (названия пунктов могут отличаться) и добавьте три переменные:
  CAPITAL_API_KEY       — API key Capital.com
  CAPITAL_IDENTIFIER    — логин/электронная почта Capital.com
  CAPITAL_API_PASSWORD  — пароль API, который был задан при создании ключа
И добавьте:
  CAPITAL_DEMO = true

Сохраните переменные и заново запустите Deploy. Не публикуйте значения этих переменных и не вставляйте их в исходный HTML.

Если позже решите использовать live API, сначала проверьте корректность цен в demo. Затем можно установить CAPITAL_DEMO=false. Для текущей задачи ордера не используются.
