Правила стратегии

1. Bollinger Bands (20, 2). Используются средняя линия и две внешние полосы для определения чрезмерного отклонения цены.

2. RSI (14). Для покупки ищем выход RSI из зоны перепроданности. Для продажи — снижение RSI после зоны перекупленности.

3. ADX (14). Новые позиции разрешены, только если ADX ниже выбранного порога. Это попытка исключить сильные направленные движения, опасные для стратегии возврата к средней.

4. Вход. Покупка: предыдущая свеча закрылась ниже нижней полосы, а текущая закрылась обратно выше неё; RSI подтверждает разворот. Продажа — зеркальное условие для верхней полосы. Вход моделируется по открытию следующей свечи.

5. Выход. Тейк-профит ставится у средней линии Bollinger на момент сигнала. Стоп рассчитывается через ATR. Если цель слишком близко относительно риска, сделка пропускается.

6. Издержки. Указанный процент цены вычитается из результата закрытой сделки как оценка суммарных расходов на вход и выход. Это приблизительная модель, а не точное воспроизведение комиссий и спреда брокера.

Важно. Win rate 70–80% — цель проверки, а не обещанный результат. Учитывай количество сделок, средний результат, Profit Factor, просадку и влияние издержек.
